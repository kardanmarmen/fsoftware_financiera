# 4.7 Pruebas del módulo

**Incremento 4:** Pagos, abonos y control de morosidad
**Responsable:** Sánchez Jimenes Jaret Isai
**Requisitos:** RNF20, RNF21, RNF22, RNF29 (y los RF de [4.1](4.1-pagos-y-morosidad.md))

## 1. Entorno

| Aspecto | Detalle |
| --- | --- |
| Pruebas de la API | Scripts que hacen las peticiones como la aplicación y comparan cada respuesta con lo esperado |
| Pruebas de pantalla | Chromium controlado por Playwright, en celular (390 px) y computadora (1280 px) |
| Base de datos | D1 local, creada desde cero con las migraciones (incluida `0006_moras`) |
| Datos | Modelo de 20 %, 16 semanas y $50 de mora; créditos de $5,000 desembolsados hace 0, 10, 15, 30 y 40 días para tener semanas vencidas |

**Resultado:** **57 comprobaciones** (36 de pagos, moras, alertas y reportes, y 21 de correcciones),
todas pasaron. Tipos de TypeScript sin errores.
