## 1. Entorno

| Aspecto | Detalle |
| --- | --- |
| Pruebas de la API | Script que hace las peticiones como la aplicación y compara cada respuesta con lo esperado |
| Pruebas de pantalla | Chromium controlado por Playwright, en tamaño de celular (390 px) |
| Base de datos | D1 local, creada desde cero con las migraciones |

de documentos), todas pasaron. Tipos de TypeScript sin errores.
